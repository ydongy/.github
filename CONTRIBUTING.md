# Contributing

Thanks for helping. These defaults apply to every repository owned by ydongy that has no `CONTRIBUTING.md` of its own.

## Before you start

- Search existing issues and pull requests first.
- For anything larger than a small fix, open an issue to discuss it before writing code.
- Read the repository's `README.md` and `AGENTS.md` for its commands and conventions.

## Making a change

1. Fork the repository and create a branch from `main`.
2. Keep the change focused: one concern per pull request.
3. Run the repository's format, build and test commands (listed in `AGENTS.md` or the README) and make sure
   they pass.
4. Update documentation and the changelog when behavior changes.
5. Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages and PR titles, for
   example `fix: handle empty input`.
6. Open a pull request and fill in the template.

## Security

Do not report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
