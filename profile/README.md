# ydongy

**English** · [简体中文](#简体中文)

Desktop apps, self-hosted tools and the websites around them. I prefer simple solutions, clear boundaries and
changes that can be verified.

## Open source (MIT)

- [sitekit](https://github.com/ydongy/sitekit): static website toolkit.
- [template-macos-app](https://github.com/ydongy/template-macos-app): starting point for a native macOS app.
- [template-mygo-app](https://github.com/ydongy/template-mygo-app): starting point for a Go desktop app with MyGo.
- [multica-orbstack](https://github.com/ydongy/multica-orbstack): Multica on OrbStack.
- [barekeep-website](https://github.com/ydongy/barekeep-website) and
  [loggia-website](https://github.com/ydongy/loggia-website): product websites.

## Products

- [Loggia](https://useloggia.com)
- [BareKeep](https://barekeep.com)

- [Repository standard](https://github.com/ydongy/.github/blob/main/STANDARD.md): how every repository is set up.

桌面应用、自托管工具，以及围绕它们的网站。我偏好简单的方案、清晰的边界，以及可以验证的改动。

### 开源项目（MIT）

- [sitekit](https://github.com/ydongy/sitekit)：静态网站工具包。
- [template-macos-app](https://github.com/ydongy/template-macos-app)：原生 macOS 应用的起步模板。
- [template-mygo-app](https://github.com/ydongy/template-mygo-app)：基于 MyGo 的 Go 桌面应用起步模板。
- [multica-orbstack](https://github.com/ydongy/multica-orbstack)：在 OrbStack 上运行 Multica。
- [barekeep-website](https://github.com/ydongy/barekeep-website) 和
  [loggia-website](https://github.com/ydongy/loggia-website)：产品网站。
