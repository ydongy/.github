# ydongy

Desktop apps, self-hosted tools and the websites around them. I prefer simple solutions, clear boundaries and
changes that can be verified.

## Open source (MIT)

- [sitekit](https://github.com/ydongy/sitekit): static website toolkit.
- [template-macos-app](https://github.com/ydongy/template-macos-app): starting point for a native macOS app.
- [template-mygo-app](https://github.com/ydongy/template-mygo-app): starting point for a Go desktop app with MyGo.
- [multica-orbstack](https://github.com/ydongy/multica-orbstack): Multica on OrbStack.
- [barekeep-website](https://github.com/ydongy/barekeep-website) and
  [loggia-website](https://github.com/ydongy/loggia-website): product websites.
